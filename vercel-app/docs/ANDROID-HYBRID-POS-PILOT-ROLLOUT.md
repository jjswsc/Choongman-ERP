# Android Hybrid POS 파일럿 롤아웃 체크리스트

## 1) 배포 단계
- 1단계: 내부 QA 단말 2대
- 2단계: 파일럿 매장 1~2개
- 3단계: 매장군 단위 점진 배포

## 2) 파일럿 전 확인
- `CAPACITOR_POS_URL`이 운영 POS 도메인으로 설정됨
- 프린터/캐시드로어 로컬 브리지 연결 확인
- 카드단말 승인 테스트(정상/거절/타임아웃) 완료
- 오프라인 큐 상태 배너 노출 확인

## 3) 필수 장애 시나리오
- 네트워크 OFF 상태에서 주문 20건 입력 후 앱 재실행
- 네트워크 ON 복귀 후 큐 자동 동기화 성공
- 중복 전송 시 주문이 1건만 생성되는지 확인(멱등키)
- `completed` 동기화 후 재고 차감 반영 확인
- 영수증/캐시드로어 실패 후 수동 재시도 확인

## 4) 운영 지표
- 오프라인 큐 평균 적체 건수
- 동기화 실패율 및 재시도 횟수
- 주문 중복 생성률(목표 0%)
- 재고 차감 누락률(목표 0%)

## 5) 장애 대응 표준
- 큐가 임계치 초과 시(예: 100건) 관리자 경고
- 10분 이상 동기화 실패 시 네트워크 점검 가이드 안내
- 단말 재부팅 후에도 큐 유지 여부 확인
- 불일치 발생 시 주문번호 기준 재처리 절차 수행
