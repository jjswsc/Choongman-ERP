# 재고조사·사용 입력 방식 변경 안내 (직원 공지)

업데이트 일자: 2025년 3월

재고조사(재고 조정)와 **사용** 탭 입력 방식이 통일되었습니다. 아래 내용 확인해 주세요.

---

## 1. 재고조사 (재고 조정)

### 변경 요약
- **표준 단위**만 사용합니다. (품목 관리에서 등록한 단위·총 수량 기준)
- **여러 행**으로 나누어 입력할 수 있고, **합계**가 자동으로 규격 기준으로 계산됩니다.

### 어떻게 바뀌었나요?
| 구분 | 내용 |
|------|------|
| **단위 선택** | 품목에 등록된 **표준 단위**만 선택 가능 (예: 규격 1개, box(6=1규격), 200g(200=1규격) 등) |
| **여러 행 입력** | 행 추가 버튼으로 단위·수량을 여러 줄 입력 가능. 각 행이 규격 기준으로 환산된 뒤 **합계**로 한 번에 반영됩니다. |
| **규격(1개)** | 입력한 숫자 = 규격 수 그대로 (예: 3 입력 → 3 규격) |
| **단위(예: 50ea)** | 입력 ÷ 총 수량 = 규격 수 (예: 50 ÷ 200 = 0.25 규격) |
| **조정 수량** | 증가: +10, 감소: -5 형식 그대로 사용 가능. 합계가 0이면 저장되지 않습니다. |
| **메모** | 사유·비고 입력란은 그대로 있습니다. |

### 참고
- 품목에 **표준 단위가 하나도 없으면** 재고 조정 시 **「규격 (1개)」**만 선택 가능합니다.
- 품목 관리에서 **표준 단위 / 총 수량**을 등록해 두면, 재고조사·사용·원가 계산에서 동일한 단위로 선택할 수 있습니다.

---

## 2. 사용 (모바일·사용 탭)

### 변경 요약
- **분수 입력이 제거**되었고, **재고조사와 같은 방식**으로 바뀌었습니다.
- **단위 선택 + 수량**을 여러 행으로 입력하고, **합계**를 확인한 뒤 장바구니에 추가합니다.

### 어떻게 바뀌었나요?
| 구분 | 내용 |
|------|------|
| **입력 방식** | 이전의 분수 입력 없음. **단위(규격/표준단위) + 수량**만 입력합니다. |
| **단위 선택** | 품목에 등록된 **표준 단위**만 선택 가능. 없으면 **「규격 (1개)」**만 표시됩니다. |
| **여러 행** | **추가** 버튼으로 행을 늘려서, 예: 2규격 + 1box(6=1규격) 처럼 섞어서 입력 가능. |
| **합계** | 행별로 규격 기준으로 환산된 **합계**가 표시됩니다. 이 합계가 장바구니에 들어갑니다. |
| **사용 수량** | 카드 제목이 **「사용 수량」**으로 표시되며, 단위 선택 칸이 조금 넓어졌습니다. |

### 흐름
1. 품목 선택
2. **사용 수량** 카드에서 **단위** 선택(규격 1개 또는 box, 200g 등) → **수량** 입력
3. 필요 시 **추가**로 행 더 넣기 → **합계** 확인
4. **사용 추가**로 장바구니에 넣기
5. 사용 확정

---

## 3. 공통 사항

- **규격** = 품목별로 정해진 “기준 단위” (예: 1규격 = 200g, 1box = 6ea 등).
- **표준 단위** = 품목 관리 > 표준 단위/총 수량에 등록한 단위. 재고조사·사용·원가 계산에서 동일하게 사용됩니다.
- 표준 단위를 등록해 두지 않은 품목은 **「규격 (1개)」**만 선택 가능하므로, 필요하면 품목 관리에서 표준 단위를 등록해 주세요.

문의사항 있으면 담당자에게 연락 부탁드립니다.
