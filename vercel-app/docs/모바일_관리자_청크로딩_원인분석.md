# 모바일에서 관리자 페이지 청크 로딩 실패 — 근본 원인 분석

## 증상
- 모바일에서 홈(/) → 관리자(/admin) 이동 시 **"Loading chunk app/admin/layout failed"** 오류
- 데스크톱에서는 정상 동작하는 경우가 많음

---

## 근본 원인 (2가지)

### 1. 실기기에서 `localhost` 사용
**가장 흔한 원인**

- 모바일 기기에서 `localhost` = **그 기기 자신**(127.0.0.1)
- PC에서 실행 중인 dev 서버는 모바일 입장에서 `localhost`로 접근 불가
- 홈은 이미 로드된 상태일 수 있지만, /admin으로 이동할 때 **새로 로드되는 layout 청크** 요청이 모바일 → PC로 가지 못함
- 에러에 `http://localhost:3000/...` 가 보이면, 모바일이 자신의 localhost로 접속 시도 중인 것

**해결**: PC IP 주소 사용
```bash
# 1. PC IP 확인 (Windows)
ipconfig

# 2. 모바일 접속용 dev 서버 실행
npm run dev:mobile

# 3. 모바일 브라우저에서 접속
# http://192.168.0.xxx:3000  (실제 PC IP로 변경)
```

### 2. Webpack 청크 로딩 불안정 (Next.js 알려진 이슈)
**두 번째 원인**

- Next.js 14+ + `--webpack` 사용 시 ChunkLoadError 보고 다수
- GitHub: [vercel/next.js#66526](https://github.com/vercel/next.js/issues/66526)
- 네트워크 지연, 한시적 끊김, 느린 모바일 연결에서 청크 요청이 실패하면 그대로 에러
- 한 번 실패 시 재시도 없이 바로 throw

**해결**:
- `webpack-retry-chunk-load-plugin` 적용 ✅ (적용 완료)
- 실패 시 최대 3회, 2초 간격으로 재시도
- 여전히 문제 시 `--turbo` 옵션 고려 (webpack custom config와 충돌 여부 확인 필요)

---

## 적용된 대응

| 조치 | 설명 |
|------|------|
| `webpack-retry-chunk-load-plugin` | 청크 로딩 실패 시 자동 재시도 |
| `dev:mobile` 스크립트 | `--host 0.0.0.0` 으로 LAN 내 다른 기기 접속 허용 |
| ErrorBoundary | ChunkLoadError 시 "다시 시도" → 전체 새로고침 |
| 관리자 버튼 `<a>` 링크 | 클라이언트 네비게이션 대신 전체 페이지 로드 |
| 로딩 타임아웃 | 6초 후 새로고침 버튼 노출 |

---

## 확인 순서

1. **모바일 접속 방식**
   - `localhost` 사용 → `http://PC_IP:3000` 으로 변경
   - `npm run dev:mobile` 로 실행했는지 확인

2. **청크 로딩/재시도**
   - 플러그인 적용 후에도 실패 → 브라우저 캐시 삭제 후 재접속
   - `.next` 폴더 삭제 후 `npm run dev` 재실행

3. **네트워크 환경**
   - PC와 모바일이 같은 Wi‑Fi에 있는지
   - 모바일 데이터 사용 시 localhost 접근 불가 (이 경우 PC 터널링 필요)
