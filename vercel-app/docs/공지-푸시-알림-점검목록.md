# 공지사항 푸시 알림 점검 목록

휴대폰에서 공지 알림이 안 올 때 아래 항목을 확인하세요.

## 1. 시스템 설정

- **설정 > 알림** 또는 admin 설정에서 `공지사항 푸시`가 **켜져 있는지** 확인
- `system_settings` 테이블: `push_notice_enabled` = 1 (또는 true)

## 2. 수신자 등록

- 공지를 받을 직원이 **홈 화면에서 "푸시 받기"** 버튼을 눌러 토큰을 등록했는지 확인
- `push_tokens` 테이블에 `store`, `name`으로 해당 직원 토큰이 있는지 확인

## 3. Firebase 설정

- **FIREBASE_SERVICE_ACCOUNT_JSON**: 서버(API) 환경 변수 설정 여부
- **NEXT_PUBLIC_FIREBASE_*** : 클라이언트 `.env.local` 또는 Vercel env 설정
- `scripts/generate-firebase-sw.cjs`가 dev/build 시 실행되어 `public/firebase-messaging-sw.js` 생성

## 4. 수신자 매칭

- **대상자 지정** 사용 시: 선택된 직원만 수신
- **매장/역할** 사용 시: `getRecipientsByTargetStoreRole`로 employees 테이블의 store, name, role/job 기준 매칭
- `employees` 테이블에 store, name이 있어야 함

## 5. 모바일 제약

- **앱 내 브라우저**(인스타그램, 카카오톡 등 웹뷰): 푸시 미지원
- **Chrome에서 직접 접속** 필수 (주소창에 URL 입력)
- **권한**: 브라우저 알림 허용
- **Android**: 5분 이상 비활성 시 배터리 최적화로 SW가 늦게 깨어날 수 있음 → TTL 3600초 설정으로 완화

## 6. 디버깅

- sendNotice API: `sendFcmToRecipients` 호출 후 `sent`, `failed` 개수 확인 (현재 콘솔 로그 없음)
- FCM이 `sent: 0, failed: 0`이면: recipients가 비어있거나, push_tokens에 토큰이 없거나, Firebase 미설정
