## 공통 (매장·본사)

### 1. 마감 원칙 — 통장 매칭

**회계 관리 → 통장 거래** (`/admin/bank-transactions`)

| 탭 | 용도 |
|---|---|
| **입력** | 은행 CSV 업로드 → 출금 용도·계정과목·거래처 확인 후 저장 |
| **조회** | 기간별 거래 조회, 실제 잔액 vs 시스템 잔액 대조, 미수·미지급·지출 연결 |
| **설명** | 적요 규칙·운영 매뉴얼 |

**매칭 순서**

1. 지출·매입·매출 등 ERP에 먼저 입력
2. 통장 CSV 업로드 또는 수동 등록
3. **입금** → 용도 `매출 수령` + 매장/거래처 → 미수금 자동 차감
4. **출금** → 용도 `매입 대금` + 거래처 → 미지급금 차감 / `경비·고정비` → 비용 분개
5. **지출 관리**에서 통장 지급한 건은 같은 출금 줄을 **이중 연결하지 않기** (화면 도움말 참고)

### 2. 증빙 규칙 (매장 POS 매출 제외)

매장 POS 매출(현금·카드·배달앱 주문)은 POS·결산·통장 `매출 수령`으로 처리 → 아래 증빙 규칙 **대상 아님**.

그 외 **모든 매출·매입·지출**에는 아래 **하나 이상** 필수:

| 증빙 | ERP 확인 위치 |
|---|---|
| **세금계산서** | **통장 거래 → 조회** — 매입 대금 출금 행 **인보이스 수령 체크** (발주·입고 연동) |
| **일반 영수증** | **지출 관리 → 발생등록** 또는 **패티 캐쉬** 등록 시 첨부·메모 |
| **지출 결의서** | **지출 관리 → 발생등록** (승인·지급 전 증빙 확인) |

세금계산서 수령 여부는 **통장 거래 조회**에서 최종 확인.

### 3. 계정과목 (패티·통장 공통)

**회계 관리 → 계정과목표(COA)** (`/admin/chart-of-accounts`)  
통장·패티·분개가 동일 DB 사용. 미분류 건은 여기서 과목 확인·추가.

## 매장 업무

### 1. 매출 — 매일 현금 입금 확인

| 순서 | 메뉴 | 경로 | 작업 |
|---|---|---|---|
| 1 | **POS → 시재 입출금** | `/admin/pos-cash` | **매출액 출금** 탭 — 해당일 현금 매출 확인 후 돈통 출금 기록 |
| 2 | **POS → 결산** | `/admin/pos-settlement` | 일별 POS 결산. 카드·Grab 등 **채널 정산** 분개 |
| 3 | **통장 거래 → 조회** | `/admin/bank-transactions` | 실제 입금 대조. **`매출 수령`** + 매장·매출일 (⚠ `revenue_*` 입금 분류 금지 — 매출 이중) |

POS 단말: **현금 관리** (`/pos/local/cash`)에서도 동일 처리 가능.

### 2. 매입 — 지두방·S&J 외 거래처

> **지두방·S&J** → 물류팀이 **입고 관리** 처리  
> **그 외 거래처** → 회계(매장)가 **받은 품목 직접 입력**

| 메뉴 | 경로 | 작업 |
|---|---|---|
| **물류 → 거래처 관리** | `/admin/vendors` | 미등록 거래처 추가 |
| **물류 → 입고 관리** | `/admin/inbound` | **신규 입고** — 날짜·매입처·품목·수량·단가 → **입고 처리** |
| | | **내역 조회** — 등록 확인·인보이스 번호 수정 |
| | | **매입처/품목 집계** — 기간별 매입 확인 |
| **회계 → 미수금 관리** | `/admin/receivable-payable` | **미지급금 (매입)** 탭 — 입고 시 자동 생성 채무 확인 |

발주 경유: **물류 → 주문 승인** (`/admin/orders`) 승인 건 **입고 등록** → 입고 화면 자동 채움.

### 3. 지출

#### 3-1. 지출 입력·지급 (원천징수·부가세)

**회계 → 지출 관리** (`/admin/expense-management`)

| 탭 | 작업 |
|---|---|
| **발생등록** | 지출 발생 등록 (원천징수·부가세·증빙 확인) |
| **지급예정** | 승인 후 **통장** 또는 **패티** 지급 |
| **지출 검색** | 과거 지출·지급 이력 |
| **카드 관리** | 법인카드 충전·사용 (해당 시) |

월말 **세무 신고** 탭과 원천·VAT 대조.

#### 3-2. 패티캐쉬 계정과목

**회계 → 패티 캐쉬** (`/admin/petty-cash`) — **계정과목 미입력** 필터로 빠진 건 점검  
과목 마스터: **계정과목표** (`/admin/chart-of-accounts`)

#### 3-3. 급여 계산

**회계 → 급여 관리** (`/admin/payroll`)

| 탭 | 작업 |
|---|---|
| **급여 계산** | 월·매장 → **계산 실행** → 수정 → **DB 저장** |
| **명세서 조회** | 저장 급여·엑셀 |
| **공휴일 관리** | 연도별 공휴일 |
| **급여 규칙** / **설명** | 산정 규칙·매뉴얼 |

**선행**: **인사 → 직원 관리** (`/admin/employees`) — 기본급·SSO 번호·입·퇴사일·SSO 제외(PND3) 여부.

### 4. 세무 (매월)

**회계 → 세무 신고** (`/admin/tax-filing`)

| 업무 | ERP 탭 | 추가 확인 |
|---|---|---|
| **SSO** 입·퇴사 | **SSO 사회보험** | **직원 관리** → xlsx → e-Service → **지급예정(회계) 반영** → 실납부 **지출 관리** |
| **P.P30** | **P.P30 / P.P36** | |
| **P.N.D 53** | **P.N.D 53 / 54** | |
| **PND1·3** | **P.N.D 1 / 3 / 91** | PND1=SSO 가입자, PND3=SSO 제외 3% |

**매장 납세자 정보** 탭: Tax ID·지점번호 — **거래처 관리** 코드와 함께 유지.

## 본사 업무

### 1. 매출

#### 물류 매출 → 미수금

| 메뉴 | 경로 | 작업 |
|---|---|---|
| **물류 → 출고 관리** | `/admin/outbound` | 매장별 출고·매출처 금액 확인 |
| **회계 → 미수금 관리** | `/admin/receivable-payable` | **미수금 (매출)** — **출고 맞춤** / **본사 미수 재동기화**(지두방·직접정산) |
| **통장 거래** | `/admin/bank-transactions` | 입금 시 **`매출 수령`** + 매장/판매처 |

#### 매월 로열티·Grab GP 청구

**회계 → PO 관리** (`/admin/accounting/purchase-order`)

| 탭 | 작업 |
|---|---|
| **청구 비율 설정** | 매장별 로열티 %·배달 GP %·Grab GP % |
| **본사 발주** | POS 매출 연동(로열티/Grab GP) → PO 저장 · 전 매장 일괄 저장 |
| **PO 이력** | 발행 내역 |

→ **미수금 (매출)** 탭 **Accounting PO** 확인 → 매장 입금 **통장 매출 수령**.

분석 참고: **매출 관리** (`/admin/sales-management`), **전체 매출** (`/admin/total-sales`).

### 2. 매입

| 메뉴 | 경로 | 작업 |
|---|---|---|
| **물류 → 입고 관리** | `/admin/inbound` | **내역 조회·집계** — 물류 입고 금액 대조 |
| **회계 → 미수금 관리** | `/admin/receivable-payable` | **미지급금 (매입)** |
| **통장 거래 → 조회** | `/admin/bank-transactions` | **매입 대금** + **입고 연동(🔗)** · **인보이스 수령 체크** |

미승인 발주: **대시보드** (`/admin`) → **주문 승인** (`/admin/orders`).

### 3. 지출

매장과 동일: **지출 관리** · **패티 캐쉬** · **급여 관리** · **통장 거래**  
본사 **물류 지출 지급예정**은 **지출 관리 → 지급예정**에서 구분 확인.

### 4. 세무

매장과 동일 화면 **세무 신고** (`/admin/tax-filing`) — 매장 **전체/개별** 전환하며 처리.

## 월별 체크리스트

| 시점 | 확인 |
|---|---|
| **매일** | 시재 입출금 → 결산 → 통장 조회(입금) |
| **수시** | 입고(지두방·S&J 외) / 지출 / 패티 계정과목 |
| **매월 초~중** | PO 관리(로열티·Grab GP) → 미수금 |
| **매월 말** | 세무 신고(SSO·PP30·PND) → SSO 납부 지출 |
| **상시** | 통장 거래 **전 건 매칭·잔액 일치** |
