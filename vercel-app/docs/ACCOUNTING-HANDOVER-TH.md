# การส่งมอบงานบัญชี (เส้นทาง ERP)

> **ฉบับภาษาเกาหลี**: [ACCOUNTING-HANDOVER-KO.md](./ACCOUNTING-HANDOVER-KO.md)  
> **SOP ที่เกี่ยวข้อง**: [ACCOUNTING_LEDGER_SOP.md](./ACCOUNTING_LEDGER_SOP.md) · [BANK_INBOUND_RECEIVABLE_FLOW.md](./BANK_INBOUND_RECEIVABLE_FLOW.md)

**เข้าใช้งาน**: ล็อกอิน ERP ผู้ดูแล → แถบด้านข้างซ้าย  
**คู่มือ**: ปุ่ม `[หน้านี้]` (ไอคอนหนังสือ) ด้านบน หรือ `/admin/help`  
**เวลา**: เขต Bangkok (Asia/Bangkok, UTC+7)

## ส่วนรวม (สาขา + สำนักงานใหญ่)

### 1. หลักการปิดบัญชี — จับคู่ธนาคาร

**บัญชี → ธนาคาร** (`/admin/bank-transactions`)

| แท็บ | ใช้ทำอะไร |
|---|---|
| **นำเข้า/บันทึก** | อัปโหลด CSV ธนาคาร → ตรวจประเภทถอน · ผังบัญชี · ผู้ค้า → บันทึก |
| **ค้นหา** | ดูรายการตามช่วงเวลา เปรียบเทียบยอดจริง vs ระบบ เชื่อมลูกหนี้/เจ้าหนี้/ค่าใช้จ่าย |
| **คำอธิบาย** | กฎคำอธิบายรายการ · คู่มือ |

**ลำดับจับคู่**

1. บันทึกค่าใช้จ่าย · ซื้อ · ขาย ใน ERP ก่อน
2. อัปโหลด CSV หรือบันทึกธนาคาร
3. **ฝาก** → ประเภท `รับชำระ (receivable_receive)` + สาขา/ผู้ค้า → หักลูกหนี้อัตโนมัติ
4. **ถอน** → ประเภท `ชำระซื้อ` + ผู้ค้า → หักเจ้าหนี้ / `ค่าใช้จ่าย/ค่าคงที่` → บันทึกบัญชี
5. ถ้าจ่ายผ่าน **การจัดการค่าใช้จ่าย** แล้ว **อย่าเชื่อมบรรทัดถอนเดิมซ้ำ** (ดูคู่มือในหน้าจอ)

### 2. หลักฐาน (ยกเว้นยอดขาย POS สาขา)

ยอดขาย POS สาขา (เงินสด · บัตร · แอปส่ง) ผ่าน POS · ปิดยอด · `รับชำระ` ธนาคาร → **ไม่ต้อง** ใช้กฎด้านล่าง

**ยอดขาย · ซื้อ · ค่าใช้จ่ายอื่นทั้งหมด** ต้องมี **อย่างน้อยหนึ่ง**:

| หลักฐาน | ตรวจใน ERP |
|---|---|
| **ใบกำกับภาษี** | **ธนาคาร → ค้นหา** — ถอนชำระซื้อ → **เช็ครับใบกำกับ** (เชื่อม PO/รับเข้า) |
| **ใบเสร็จทั่วไป** | **การจัดการค่าใช้จ่าย → ลงทะเบียน** หรือ **Petty Cash** แนบ/หมายเหตุ |
| **ใบขอเบิก/ใบอนุมัติจ่าย** | **การจัดการค่าใช้จ่าย → ลงทะเบียน** ก่อนอนุมัติ/จ่าย |

สถานะรับใบกำกับภาษี ตรวจสุดท้ายที่ **ธนาคาร → ค้นหา**

### 3. ผังบัญชี (Petty + ธนาคาร ใช้ชุดเดียวกัน)

**บัญชี → ผังบัญชี** (`/admin/chart-of-accounts`)  
ธนาคาร · Petty · บันทึกบัญชี ใช้ DB เดียวกัน ตรวจ/เพิ่มบัญชีที่นี่

## งานสาขา

### 1. ขาย — ตรวจเงินสดฝากทุกวัน

| ลำดับ | เมนู | URL | งาน |
|---|---|---|---|
| 1 | **POS → เงินสดเข้าออก** | `/admin/pos-cash` | แท็บ **ถอนจากยอดขาย** — บันทึกถอนเงินสดจากลิ้นชัก |
| 2 | **POS → ปิดยอด** | `/admin/pos-settlement` | ปิดยอดรายวัน · **ชำระช่องทาง** (บัตร/Grab ฯลฯ) |
| 3 | **ธนาคาร → ค้นหา** | `/admin/bank-transactions` | เปรียบเทียบฝากจริง · **`รับชำระ`** + สาขา/วันขาย (⚠ ห้าม `revenue_*` — ยอดขายซ้ำ) |

POS หน้าร้าน: **จัดการเงินสด** (`/pos/local/cash`) ทำได้เหมือนกัน

### 2. ซื้อ — ยกเว้น Jidubang · S&J

> **Jidubang · S&J** → ทีมโลจิสติกส์ **รับเข้า**  
> **ผู้ค้าอื่น** → บัญชีสาขา **ลงรายการที่รับเอง**

| เมนู | URL | งาน |
|---|---|---|
| **โลจิสติกส์ → ผู้ค้า** | `/admin/vendors` | เพิ่มผู้ค้าใหม่ |
| **โลจิสติกส์ → รับเข้า** | `/admin/inbound` | **รับเข้าใหม่** — วันที่ · ผู้ขาย · สินค้า · จำนวน · ราคา → **บันทึกรับเข้า** |
| | | **ประวัติ** — ตรวจ/แก้เลขใบกำกับ |
| | | **สรุปผู้ขาย/สินค้า** — สรุปช่วงเวลา |
| **บัญชี → ลูกหนี้/เจ้าหนี้** | `/admin/receivable-payable` | แท็บ **เจ้าหนี้ (ซื้อ)** — หนี้จากรับเข้า |

จาก PO: **อนุมัติคำสั่งซื้อ** (`/admin/orders`) → ปุ่ม **ลงรับเข้า** → ฟอร์มเติมอัตโนมัติ

### 3. ค่าใช้จ่าย

#### 3-1. ลงรายการและจ่าย (หัก ณ ที่จ่าย · VAT)

**บัญชี → การจัดการค่าใช้จ่าย** (`/admin/expense-management`)

| แท็บ | งาน |
|---|---|
| **ลงทะเบียนรายการ** | บันทึกค่าใช้จ่าย (หัก ณ ที่จ่าย · VAT · หลักฐาน) |
| **แผนชำระ** | อนุมัติแล้วจ่ายผ่าน **ธนาคาร** หรือ **Petty** |
| **ค้นหารายจ่าย** | ประวัติ |
| **จัดการบัตร** | บัตรองค์กร (ถ้ามี) |

ท้ายเดือน เปรียบเทียบกับ **การยื่นภาษี**

#### 3-2. Petty Cash — ผังบัญชี

**บัญชี → Petty Cash** (`/admin/petty-cash`) — กรอง **บัญชีว่าง**  
ผังบัญชีหลัก: **ผังบัญชี** (`/admin/chart-of-accounts`)

#### 3-3. คำนวณเงินเดือน

**บัญชี → เงินเดือน** (`/admin/payroll`)

| แท็บ | งาน |
|---|---|
| **คำนวณ** | เลือกเดือน/สาขา → **คำนวณ** → แก้ไข → **บันทึก DB** |
| **รายการเงินเดือน** | ดู/Excel |
| **วันหยุด** | วันหยุดรายปี |
| **กฎเงินเดือน** / **คำอธิบาย** | กฎ · คู่มือ |

**ก่อนหน้า**: **พนักงาน** (`/admin/employees`) — เงินเดือนพื้นฐาน · เลข SSO · วันเข้า-ออก · ยกเว้น SSO (PND3)

### 4. ภาษี (รายเดือน)

**บัญชี → การยื่นภาษี** (`/admin/tax-filing`)

| งาน | แท็บ ERP | เพิ่มเติม |
|---|---|---|
| **SSO** เข้า-ออก | **ประกันสังคม SSO** | **พนักงาน** → xlsx → e-Service → **สะท้อนแผนชำระ(บัญชี)** → จ่ายจริงที่ **การจัดการค่าใช้จ่าย** |
| **ภ.พ.30** | **P.P30 / P.P36** | |
| **ภ.ง.ด.53** | **P.N.D 53 / 54** | |
| **ภ.ง.ด.1·3** | **P.N.D 1 / 3 / 91** | ภ.ง.ด.1=มี SSO · ภ.ง.ด.3=ไม่มี SSO หัก 3% |

แท็บ **ข้อมูลผู้เสียภาษีรายสาขา**: Tax ID · เลขสาขา — คู่กับรหัส **ผู้ค้า**

## งานสำนักงานใหญ่ (HQ)

### 1. ขาย

#### ยอดขายโลจิสติกส์ → ลูกหนี้

| เมนู | URL | งาน |
|---|---|---|
| **โลจิสติกส์ → ส่งออก** | `/admin/outbound` | ตรวจยอดส่งออก/ผู้ซื้อ |
| **บัญชี → ลูกหนี้/เจ้าหนี้** | `/admin/receivable-payable` | **ลูกหนี้ (ขาย)** — **Sync ส่งออก** / **Sync ลูกหนี้ HQ** (Jidubang/ชำระตรง) |
| **ธนาคาร** | `/admin/bank-transactions` | ฝาก → **`รับชำระ`** + สาขา/ผู้ซื้อ |

#### Royalty · Grab GP รายเดือน

**บัญชี → จัดการ PO** (`/admin/accounting/purchase-order`)

| แท็บ | งาน |
|---|---|
| **อัตราเรียกเก็บ** | % Royalty · GP ส่ง · Grab GP ต่อสาขา |
| **สั่งซื้อ HQ** | ดึงยอด POS (Royalty/Grab GP) → บันทึก PO · บันทึกทุกสาขา |
| **ประวัติ PO** | ตรวจรายการ |

→ แท็บ **ลูกหนี้ (ขาย)** ประเภท **Accounting PO** → สาขาโอน → **`รับชำระ`** ธนาคาร

วิเคราะห์: **จัดการยอดขาย** (`/admin/sales-management`), **ยอดขายรวม** (`/admin/total-sales`)

### 2. ซื้อ

| เมนู | URL | งาน |
|---|---|---|
| **โลจิสติกส์ → รับเข้า** | `/admin/inbound` | **ประวัติ/สรุป** — เปรียบยอดทีมโลจิสติกส์ |
| **บัญชี → ลูกหนี้/เจ้าหนี้** | `/admin/receivable-payable` | **เจ้าหนี้ (ซื้อ)** |
| **ธนาคาร → ค้นหา** | `/admin/bank-transactions` | **ชำระซื้อ** + **เชื่อมรับเข้า(🔗)** · **เช็ครับใบกำกับ** |

PO ค้างอนุมัติ: **แดชบอร์ด** (`/admin`) → **อนุมัติคำสั่งซื้อ** (`/admin/orders`)

### 3. ค่าใช้จ่าย

เหมือนสาขา: **การจัดการค่าใช้จ่าย** · **Petty Cash** · **เงินเดือน** · **ธนาคาร**  
HQ มี **แผนชำระโลจิสติกส์** แยกใน **แผนชำระ** — ตรวจให้ครบ

### 4. ภาษี

หน้าเดียวกับสาขา **การยื่นภาษี** (`/admin/tax-filing`) — สลับ **ทุกสาขา/รายสาขา**

## Checklist รายเดือน

| ช่วง | ตรวจ |
|---|---|
| **ทุกวัน** | เงินสดเข้าออก → ปิดยอด → ธนาคาร(ฝาก) |
| **ตลอดเวลา** | รับเข้า(ยกเว้น Jidubang/S&J) / ค่าใช้จ่าย / Petty บัญชี |
| **ต้น-กลางเดือน** | PO (Royalty·Grab GP) → ลูกหนี้ |
| **ปลายเดือน** | ยื่นภาษี (SSO·PP30·PND) → จ่าย SSO |
| **ตลอด** | ธนาคาร **จับคู่ครบ · ยอดตรง** |
