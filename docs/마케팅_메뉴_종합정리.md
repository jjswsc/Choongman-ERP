# 마케팅 메뉴 종합 정리

> **기본 설계**: `마케팅_메뉴_설계안.md` 참조  
> **기준**: `_Report - Marketing campaign results 2025.xlsx` (현행 엑셀)  
> **목표**: 엑셀 수작업 → ERP 통합 관리, POS·회계·원가와 연동

---

## 1. 전체 구조 한눈에

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           마케팅 메뉴 (vercel-app)                                │
├─────────────────────────────────────────────────────────────────────────────────┤
│  경로: /admin/marketing/*                                                         │
│  위치: 사이드바 > 마케팅 관리 (별도 대메뉴, 매출 관리 아래)                       │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│  마케팅 관리 (별도 대메뉴)                                                        │
│  ├── 캠페인        → /admin/marketing/campaigns                                  │
│  ├── 광고 ROAS     → /admin/marketing/ads                                         │
│  ├── 인플루언서    → /admin/marketing/influencers                                 │
│  ├── 실적 대시보드 → /admin/marketing/dashboard                                   │
│  └── 비용 연계     → /admin/marketing/costs                                       │
│                                                                                  │
│  연동: POS 매출  ←→  회계(은행/petty)  ←→  원가분석  ←→  (추후) LINE OA           │
│                                                                                  │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## 2. 단계별 구축 로드맵

### Phase 1: 기본 (필수)

| # | 작업 | 산출물 | 예상 |
|---|------|--------|------|
| 1 | DB 테이블 생성 | `marketing_campaigns`, `marketing_ads`, `marketing_influencers`, `marketing_campaign_branches` | 1일 |
| 2 | 마케팅 페이지 + 캠페인 탭 CRUD | `/admin/marketing`, 캠페인 목록/등록/수정/삭제 | 2일 |
| 3 | 엑셀 가져오기 API | Promotion-Campaign, ROAS, Influencer 시트 파싱 → DB 적재 | 1일 |
| 4 | POS 연계 API | 캠페인 기간·채널·지점 기준 매출 집계 (`pos_sales_details`) | 2일 |
| 5 | 광고·인플루언서 탭 | ROAS 입력, 인플루언서 목록, CPF 등 | 1~2일 |
| 6 | 회계 연계 | `bank_transactions` memo 규칙 → campaign_id 매핑, 비용 집계 | 1~2일 |
| 7 | 실적 대시보드 | KPI vs 실적 차트, 지점별 비교 | 2일 |

**Phase 1 완료 시**: 엑셀 대체, 실적·비용 자동 집계, KPI vs 실적 한 화면 확인 가능.

### Phase 2: 고도화 (추천)

| # | 작업 | 효과 | 예상 |
|---|------|------|------|
| 1 | POS·쿠폰 정밀 연계 | `pos_promos`, `pos_coupons`에 `marketing_campaign_id` → 실제 적용 주문만 집계 | 1~2일 |
| 2 | **프로모션 세트 시뮬레이터** | 메뉴 조합 + 할인 → 원가·마진·수익성 즉시 확인 | 1~2일 |
| 3 | 원가·마진 연계 | 프로모션 메뉴 원가 → ROI, 손익 분석 | 1일 |

| 5 | 캠페인 템플릿 | CM Set 2·3 등 반복 프로모션 템플릿 복사 | 0.5일 |
| 6 | 예산 알림 | 실비>예산, KPI 달성률, 캠페인 D-day | 1일 |
| 7 | 통합 캘린더 | 캠페인·광고·인플루언서 일정 한 화면 | 1일 |
| 8 | 월간 리포트 | PDF/Excel 자동 생성 | 1일 |

## 4. DB 스키마 (요약)

| 테이블 | 용도 |
|--------|------|
| `marketing_campaigns` | 캠페인 마스터 (제목, 형식, 기간, 지점, 비용 항목, KPI, 결론) |

## 5. UI 탭별 기능

| 메뉴(페이지) | 입력 | 출력 | 연동 |
|--------------|------|------|------|
| **캠페인** | 제목, 형식, 기간, 지점, 할인, 비용, KPI, 결론 | 목록, 상세, [세트 시뮬레이션] | POS 실적, 엑셀 가져오기 |
| **광고 ROAS** | 포스트, 플랫폼, 예산, 실비, 링크 | ROAS(매출/광고비) | 캠페인 선택 |
| **인플루언서** | 이름, 팔로워, 지점, 비용, 링크 | CPF, 도달 추정 | 캠페인 선택 |
| **실적 대시보드** | (필터: 기간, 캠페인, 지점) | KPI vs 실적 차트, 마진·ROI | POS, 회계 |
| **비용 연계** | 은행/petty 거래 ↔ 캠페인 매핑 | 캠페인별 비용 합계 | bank_memo_rules |

## 8. POS·회계 연동 요약

### POS
- `pos_sales_details`: channel(Lineman/Table/Packing), menu_name, sales_datetime, pos
- 매칭: 기간 ∈ [start_date, end_date], channel ↔ format, pos ∈ branches
- Phase 2: `pos_promos.marketing_campaign_id` → 프로모션 적용 주문만 집계

### 회계
- `bank_transactions`, `petty_cash`: memo에 `marketing_campaign_id:xxx` 또는 bank_memo_rules
- 마케팅 비용 계정과목: Advertising, Marketing-Offline, Influencer fee 등

---

## 9. 프로모션 세트 시뮬레이터 (Phase 2)

**위치**: 캠페인 탭 내 버튼 또는 POS 프로모션 등록 화면

**입력**: 메뉴 선택, 수량, 세트 판매가(또는 할인율)

**출력**: 정가 합계, 원가, 마진(฿, %), 목표 주문 시 예상 이익

**연계**: `getPosMenuCostAnalysis` / `getMenuCost`

---

## 10. LINE OA 연계 (Phase 3)

**현황**: Line OA 회원 다수 확보

**API**: Messaging API, LIFF, Account Linking, Membership API, Broadcast

**활용**: 생일 20% 쿠폰, 3개월 미방문 타겟 푸시, 포인트·주문 이력, 쿠폰 사용 추적

**사전**: LINE Developers 채널, LIFF 앱, Webhook 서버, OA 구독 플랜

## 11. 구현 순서 (권장)

```
1. Supabase 마케팅 테이블
2. 마케팅 페이지 라우트 + 사이드바 메뉴
3. 캠페인 탭 (CRUD)
4. 엑셀 가져오기
5. POS 실적 집계 API + 캠페인 상세에 표시
6. 광고·인플루언서 탭
7. 회계 연계 + 비용 연계 탭
8. 실적 대시보드
───────────────────────────
9. (Phase 2) pos_promos/pos_coupons campaign_id
10. (Phase 2) 프로모션 세트 시뮬레이터
11. (Phase 2) 원가·마진, CPF, 템플릿, 알림, 캘린더, 리포트
───────────────────────────
12. (Phase 3) LINE OA, 광고 API, A/B 비교, 다국어
```
