# CM ERP 프로젝트 규모

> 매장·유통·인사 통합 관리 시스템 (Choongman ERP)

---

## 📊 코드 규모 (총계)

| 구분 | 라인 수 | 파일 수 | 비고 |
|------|---------|---------|------|
| **TypeScript/TSX** | 약 91,800줄 | 523개 | vercel-app (프론트·API·lib) |
| **SQL** | 약 4,300줄 | 130개 | 마이그레이션·스키마 |
| **CSS** | 약 570줄 | 2개 | vercel-app |
| **총계** | **약 96,700줄** | **655개+** | 소스 코드 기준 |

| 항목 | 수량 |
|------|------|
| API 엔드포인트 | **264개** |

---

## 📁 주요 기능 모듈

| 모듈 | 내용 |
|------|------|
| **POS** | 주문, 결제, 테이블 배치, 메뉴·프로모션·쿠폰, 결산 |
| **물류** | 발주, 입고, 출고, 재고, 품목·거래처 |
| **인사** | 직원, 급여, 근태, 휴가, 평가, 스케줄 |
| **재무** | 은행거래, 고정비, 미수·미지급, 손익계산서 |
| **마케팅** | 캠페인, 광고 ROAS, 인플루언서 |
| **인테리어** | 프로젝트, 비용, 직매입, 주방설비, 사양서, 일정 |
| **기타** | 공지, 컴플레인, 매장방문, 업무일지, 원가분석 등 |

---

## 🛠️ 기술 스택

- **프론트**: Next.js 16, React 19, TypeScript, Tailwind CSS
- **백엔드**: Supabase (PostgreSQL), Next.js API Routes
- **다국어**: ko, en, th, mm, la (5개 언어)
- **배포**: Vercel
