# 마케팅 메뉴 구현 작업 계획

> **작업 순서**: 의존성 순. 하위 작업은 상위 완료 후 진행.

---

## Phase 1: 기본 인프라

### Step 1. DB 테이블 생성
**산출물**: `supabase_marketing.sql`  
**내용**:
- `marketing_campaigns` (캠페인 마스터)
- `marketing_ads` (광고 포스트)
- `marketing_influencers` (인플루언서)
- `marketing_campaign_branches` (캠페인-지점 매핑, 또는 campaigns.branches JSONB)

**컬럼 핵심**:
- campaigns: topic, format, status, detail, start_date, end_date, branches, discount_type, discount_value, cost_ads_online, cost_ads_offline, cost_production, cost_food, cost_influencer, budget_total, kpi_target, kpi_unit, conclusion
- ads: campaign_id, content_format, content_pillar, content_topic, publish_date, platform, post_link, boost_budget, actual_spent
- influencers: campaign_id, name, followers, content_format, content_topic, branch_review, hire_type, budget, shooting_date, publish_date, platform_links (JSONB)

---

### Step 2. API - 캠페인 CRUD
**산출물**: 
- `GET /api/marketingCampaigns` (목록)
- `POST /api/marketingCampaigns` (등록)
- `GET /api/marketingCampaigns/[id]` (상세)
- `PATCH /api/marketingCampaigns/[id]` (수정)
- `DELETE /api/marketingCampaigns/[id]` (삭제)

**참고**: `lib/api-client.ts`에 `getMarketingCampaigns`, `saveMarketingCampaign` 등 함수 추가

---

### Step 3. 캠페인 페이지 (목록 + 등록/수정 폼)
**경로**: `/admin/marketing/campaigns`  
**기능**:
- 목록 테이블 (제목, 형식, 기간, 지점, 상태, KPI)
- [추가] 버튼 → 폼 다이얼로그/페이지
- 행 클릭 → 수정 폼
- 삭제

**UI 패턴**: `pos-coupons`, `pos-promos` 페이지 참고 (테이블 + 폼)

---

### Step 4. API - 광고·인플루언서 CRUD
**산출물**:
- `GET/POST /api/marketingAds`
- `GET/POST /api/marketingInfluencers` (또는 PATCH/DELETE 포함)

---

### Step 5. 광고 ROAS 페이지
**경로**: `/admin/marketing/ads`  
**기능**:
- 광고 목록 (캠페인, 플랫폼, 예산, 실비, 링크)
- 등록/수정 폼
- 캠페인 선택 (dropdown)

---

### Step 6. 인플루언서 페이지
**경로**: `/admin/marketing/influencers`  
**기능**:
- 인플루언서 목록 (이름, 팔로워, 지점, 비용, 플랫폼)
- 등록/수정 폼
- CPF 계산 (비용÷팔로워) - 나중에 추가 가능

---

### Step 7. 엑셀 가져오기 API
**산출물**: `POST /api/importMarketingExcel`  
**내용**:
- Promotion-Campaign 시트 → marketing_campaigns
- ROAS 시트 → marketing_ads (행당 여러 플랫폼 → 다중 행)
- Influencer 시트 → marketing_influencers
- Excel serial date 변환
- 지점명 정규화

**위치**: 캠페인 페이지 상단 [엑셀 가져오기] 버튼

---

## Phase 2: 연동

### Step 8. POS 연계 API
**산출물**: `GET /api/marketingCampaignResults?campaignId=&importId=`  
**로직**:
- `pos_sales_details`에서 import_id, sales_datetime, channel, pos, payment_amount 조회
- campaign 기간·지점·format(Delivery/Dine in) 매칭
- dine_in_orders, delivery_orders, dine_in_sales, delivery_sales 집계

**표시**: 캠페인 상세에 "POS 실적" 영역

---

### Step 9. 회계 연계 API
**산출물**: `GET /api/marketingCampaignCosts?campaignId=`  
**로직**:
- `bank_transactions`, `petty_cash`에서 memo에 campaign_id 또는 campaign명 포함 시 합산
- 또는 `bank_memo_rules` 확장으로 marketing_campaign_id 매핑

**표시**: 캠페인 상세에 "실제 비용" 영역

---

### Step 10. 비용 연계 페이지
**경로**: `/admin/marketing/costs`  
**기능**:
- 캠페인별 비용 합계 (예산 vs 실비)
- 은행/petty 거래에서 campaign 매핑 UI (선택)
- 또는 bank_memo_rules에 campaign 키워드 추가 UI

---

### Step 11. 실적 대시보드 페이지
**경로**: `/admin/marketing/dashboard`  
**기능**:
- 캠페인별 KPI vs 실적 차트 (BarChart, recharts)
- 지점별 비교 테이블
- 기간 필터
- 데이터 소스: marketing_campaigns + marketingCampaignResults API

---

## Phase 3: 고도화 (선택)

- 프로모션 세트 시뮬레이터
- pos_promos/pos_coupons에 campaign_id 연계
- 원가·마진 연계
- LINE OA 연동
